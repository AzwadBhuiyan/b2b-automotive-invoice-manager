# Custom Invoice & Tax Management System

A locally hosted PHP web application originally developed for Desai International Ltd., an automotive parts importer based in Bangladesh. With their authorization, this project has been made open-source to help similar businesses automate and streamline their B2B billing and tax calculations.

## Features
- **Automated Tax Calculation:** Dynamically computes total prices and VAT, eliminating manual entry errors.
- **PDF Exporting:** Generates formatted invoices with a single click for immediate distribution and record-keeping.
- **Local Deployment:** Optimized to run entirely offline on a local server environment, ensuring data privacy and fast operation.

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

## Installation
1. Clone this repository into your local server's root directory (e.g., `htdocs` for XAMPP).
2. Create a new MySQL database named `desai_invoicing`.
3. Import the provided `database.sql` file into your new database.
4. Open `config.php` and update it with your database credentials.
5. Launch your local server (Apache and MySQL) and navigate to the project directory in your browser.
